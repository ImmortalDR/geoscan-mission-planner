# Происхождение компонентов

Этот репозиторий содержит самостоятельный исходный снимок MVP. H1 и H2
не являются Git submodule: новый клон получает код и тесты всех трёх частей.

| Часть | Источник снимка на 25.09.2026 | Состав |
| --- | --- | --- |
| H1 | Локальный канон `/root/h1`, коммит родительского дерева `6640f920` | `h1/h1_coverage`, контракты, тестовые fixtures и документация без исследовательских PDF |
| H2 | Локальный `main` `/root/h2`, коммит `940ff82` | Git subtree в `h2/`, включая код, тесты и viewer |
| H3 | `ImmortalDR/geoscan`, базовый коммит `e7940fb` | API, UI, доставка и независимая проверка |
| Dataset | Проверенный локальный `/root/h3/data` | Исходные сцены, эталоны, DSM, атрибуция и `manifest.json` |

Исходный remote H2 (`TPRozov/H2_Optimize_4D`) недоступен для push с этого
сервера. Снимок кода включён напрямую, чтобы сборка и проверка не зависели от
доступа к чужому GitHub-репозиторию. Для будущих обновлений H2 используйте
отдельный review/PR и заново запускайте контрактные и интеграционные тесты.

В `h1/h1_coverage/fixtures/conformance` используется относительная ссылка на
включённый каталог `datasets/geoscan_customer_conformance`; в ней нет ссылок
на `/root`. Сгенерированное состояние, секреты, сертификаты и локальные
артефакты не входят в исходный репозиторий.

Демонстрационные маршруты проверены в объявленной модели, но глобальная
оптимальность не доказана. `SAFE` не является разрешением реального полёта.
