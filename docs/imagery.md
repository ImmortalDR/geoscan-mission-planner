# Реальные картографические подложки H3

Добавлены локальные RGB-снимки для МГУ, Переделкино и Орехово - Домодедовской.
Это настоящие данные Sentinel-2C за **28 мая 2025 года**, а не сгенерированные
изображения. Исходное разрешение 10 м/пиксель. Оно подходит для обзора района,
но не для точного осмотра небольших объектов или проверки препятствий.

## Источник и лицензия

- [Публичный каталог Sentinel-2 COG](https://registry.opendata.aws/sentinel-2-l2a-cogs/).
- [Условия Copernicus Sentinel](https://cds.climate.copernicus.eu/licences/ec-sentinel).
- [Снимок 37UDB](https://earth-search.aws.element84.com/v1/collections/sentinel-2-l2a/items/S2C_37UDB_20250528_0_L2A).
- [Снимок 37UCB](https://earth-search.aws.element84.com/v1/collections/sentinel-2-l2a/items/S2C_37UCB_20250528_0_L2A).

Атрибуция: **Contains modified Copernicus Sentinel data 2025**.
Исходные данные преобразованы в COG компанией Element 84. В поставке сохранены
оригинальные STAC-описания, точные ссылки, даты и SHA-256 локальных файлов.
Облачность целых исходных тайлов: 0.003249% и 0.000747%; это не измерение
облачности каждого локального фрагмента. Все три фрагмента визуально просмотрены.

Слой OpenStreetMap остаётся онлайн-картой. Его тайлы не скачиваются архивом:
[политика стандартного OSM-сервера](https://operations.osmfoundation.org/policies/tiles/)
запрещает массовую предзагрузку и офлайн-архивы.

## Географическая привязка

`web/h3/imagery/manifest.json` описывает три подложки. Каждый фрагмент покрывает
все GeoJSON-слои своей сцены, включая площадки и разрешённую область, с буфером
около 2 км. Читаются только нужные окна COG, без скачивания исходных файлов
целиком. МГУ использует соседние тайлы одного пролёта.

RGB-GeoTIFF перепроецирован в EPSG:3857; JPEG для браузера получен из того же
массива пикселей. Углы JPEG записаны в WGS84 в порядке NW, NE, SE, SW, поэтому
подложка и векторная геометрия совпадают в MapLibre. Перепроецирование не
повышает фактическое разрешение снимка.

RGB-GeoTIFF является изображением, **не моделью высот**. Он не подменяет
`dem.tif`, ограничения воздушного пространства или реестр препятствий. Никакие
координаты задач, исходные сцены и сертификаты ради подложек не меняются.

## Повторная подготовка и проверка

Из корня приложения, в окружении с его зависимостями:

```bash
.venv/bin/python scripts/prepare_h3_imagery.py \
  --dataset /root/h3/data \
  --output /tmp/h3-imagery-new
PYTHONPATH=src .venv/bin/python -m pytest tests/api/test_h3_imagery.py -q
```

Скрипт отказывается перезаписывать готовый manifest и не сохраняет частично
покрытые подложки. Тесты проверяют контрольные суммы, геопривязку, покрытие,
размеры и непустые пиксели. Загрузка снимков с внешнего источника нужна только
при подготовке, браузер получает JPEG с собственного сервера.
