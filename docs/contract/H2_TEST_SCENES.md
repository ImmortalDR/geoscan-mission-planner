# Сценарии для проверки H2

Шаблоны открываются в общем интерфейсе `web/h3/` через «Открыть…».
Простой шаблон можно считать сразу; изменённый — сохранить как собственный.
Сохранение сценария не сохраняет результаты расчёта: для них есть экспорт.

Используйте экранные номера:

| Шаблон | Проверка |
| --- | --- |
| S00 | Первый полный расчёт, покрытие и экспорт |
| S03 | Объяснимый отказ из-за недостижимости |
| S12 | Световой день и запретное временное окно |
| S18 | Разные старт/финиш, промежуточная дозарядка, обе метрики |
| S19 | Много зон и групповой расчёт |

Внутренние идентификаторы файлов отличаются от экранной нумерации и
сохранены для совместимости. Соответствие формирует `gmp.api.scenario_catalog`.

Локальные команды — в [README H2](../../h2/README.md).
