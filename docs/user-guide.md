# Руководство пользователя

1. Войдите с выданной учётной записью. Во второй строке нажмите «Открыть»:
   шаблоны, свои сохранённые сценарии или загрузка файлов находятся в одном окне.
2. Простые тесты имеют номера S00–S09, сложные примеры с реальным рельефом —
   S10–S19. Номера относятся к интерфейсу; внутренние идентификаторы файлов
   сохранены для совместимости. Шаблон уже сохранён и готов к запуску.
3. Загрузите JSON параметров, GeoJSON/KML слоёв, GeoTIFF высот или ZIP-комплект.
   При отсутствии рельефа выберите загрузку Copernicus, плоскую поверхность
   либо отложите решение. Источник высот показывается в сцене.
4. Проверьте зоны, датчики, ветер, временные окна и БВС. В таблице площадок
   задайте старт, конечную посадку и допустимые промежуточные зарядки.
   «Любая» означает любую подходящую штатную площадку. Резервные площадки
   используются для аварийной достижимости и не выбираются штатным финишем.
5. В условиях миссии задайте минуты подготовки до первого вылета, обслуживания
   между вылетами и снятия данных после последней посадки. Подготовка группы
   считается параллельной; снятие данных — общим завершающим этапом. Оба
   крайних этапа резервируют время внутри пересечения окна миссии и светового
   окна. В старых входах отсутствующие длительности равны нулю; итог явно
   сообщает, если они заданы не полностью. Налёт и заряд учитывают только полёт.
6. Изменения шаблона сохраните через «Сохранить как». Свой сценарий можно
   сохранять обычной кнопкой. Сам расчёт не меняет исходный сценарий.
7. Выберите критерий: время завершения работ или суммарный налёт. Нажмите
   «Рассчитать». Поиск автоматически заканчивается по объёму работы/стагнации;
   задача не обязана занимать весь верхний бюджет. Seed фиксирован.
8. В результате смотрите крупную метрику, покрытие, галсы, граф, маршруты,
   расписание и независимые проверки. SAFE означает прохождение модели.
   Неполный план/неудача поиска не равны доказанной невозможности.
9. Во вкладке «Экспорт» скачайте KML/GeoJSON для всей группы или одного БВС;
   оба файла содержат линии и полные точки со временем, высотами, скоростями
   и фазами. JSON сохраняет полный результат, PDF/DOCX — отчёт.
   [Точный формат](flight-export.md). Экспортируйте результаты отдельно,
   прежде чем закрывать сценарий, если они нужны как постоянный артефакт.

Быстрое демо: S00 (первая съёмка), S03 (слишком дальняя база — отказ),
S12 (световой день и перерыв), S18 (дозарядка между разными стартом и финишем),
S19 (большой набор зон, оба критерия). Номера здесь — новые экранные номера.
# Открытый доступ

В публичном развёртывании (`GMP_PUBLIC_ACCESS=1`) сайт открывается без пароля:
посетитель автоматически получает роль планировщика в общем рабочем пространстве.
Можно открывать шаблоны, загружать и сохранять сценарии, выполнять расчёты и
экспортировать результаты. Административные операции недоступны. Сессионная
cookie и проверка CSRF остаются включены. По умолчанию публичный доступ выключен;
настройка применяется отдельно к каждому экземпляру сервиса.
