# H3 demo path

Владелец прогона: Данила Бессмертный. Результат ручного прогона записывается
отдельно: автоматические тесты не подменяют приёмку человеком.

## Основной проход

Актуальная последовательность и экранные номера: [руководство](user-guide.md).
Откройте S18, запустите оба критерия, проверьте покрытие и дозарядку,
экспортируйте KML/GeoJSON для всех БВС и отдельно одного аппарата.
В KML откройте папку точек: время, AGL/AMSL, скорость, фаза и остаток ресурса.
В GeoJSON фильтруйте `feature_type=sortie` или `waypoint`.
Для отрицательного примера используйте S03; для временных окон — S12,
для большого набора зон — S19. Сохранение сценария и результатов разделены.

На демонстрации не показывайте пароли и cookies. SAFE — результат независимой
проверки модели, а не разрешение реального полёта. Неудача поиска не является
доказанным INFEASIBLE. Для резервной демонстрации сохраните файлы результатов
и запись экрана именно проверенной версии.
