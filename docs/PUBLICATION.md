# Состав конкурсной поставки

Репозиторий самодостаточен: код H1/H2/H3, готовый интерфейс, зависимости,
шаблоны с рельефом, тестовые данные, тесты, документация и средства запуска.
Основная инструкция — [README](../README.md).

## Что сохраняется

Исходники всех расчётных модулей и их совместимые CLI, тесты и фикстуры,
GeoTIFF/GeoJSON/KML, эталонные ответы, атрибуция данных и лицензии библиотек.
`data/` используется приложением и независимой проверкой эталонов;
`datasets/` — модульными тестами и проверками совместимости.
Это разные наборы: удалять один как копию другого нельзя.

`docs/evidence/` содержит отобранные протоколы с границами применимости.
Промежуточные снимки разработки, старый отдельный H2-viewer, переписка,
внутренние планы передачи проекта и прежние серверные скрипты исключены.
Рабочие БД, загруженные сцены, результаты пользователей, `.venv/`, кэши,
секреты и резервные копии не входят в Git и не нужны для первого запуска.

## Чистый архив

После коммита изменений можно получить переносимый снимок без истории Git:

```bash
python3 scripts/prepare_public_repo.py /tmp/geoscan-submission
```

Каталог назначения должен отсутствовать. Скрипт копирует отслеживаемые файлы,
проверяет внешние symlink, подозрительные имена и распространённые форматы
секретов. В выходной каталог добавляется `PUBLIC_MANIFEST.json` с SHA-256
файлов и исходным коммитом. Манифест генерируется для конкретного архива,
а не хранится в репозитории, где он устаревал бы при любой правке.
Проверка известных форматов секретов не является универсальным аудитом.

Для сдачи используйте URL корня репозитория. Презентация и демонстрационное
видео подготавливаются отдельно; наличие исходников не означает загрузку
всех материалов на платформу конкурса.
