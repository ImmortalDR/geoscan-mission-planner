# Открытие и сохранение сценариев — 27.09.2026

Проверено на https://45.87.246.124:9443/. Исходники сервиса: `/root/h3`.

## Поведение

- Одна кнопка «Открыть…» во второй строке: шаблоны, свои сохранённые сценарии,
  импорт файлов, создание пустого сценария. Сохранение и «Сохранить как» там же.
- Шаблон готов к запуску сразу. Его нельзя перезаписать. После правок нужно
  «Сохранить как»; собственный сценарий поддерживает обычное сохранение.
- Полный импортированный набор файлов также готов к запуску после валидации.
  Добавление отдельного файла к текущему сценарию создаёт изменённую версию.
- Расчёт не меняет исходные данные и статус сохранения. При повторном открытии
  расчёт не восстанавливается. Его результаты экспортируются отдельно.
  Серверные записи запусков сохраняются для логов и проверки сертификатов.
- Шаблоны и импорт используют общую серверную обработку файлов и один путь
  LIVE H1 → H2 → H3. Отличается только происхождение и защита шаблона от записи.
- Диалог о рельефе появляется только при отсутствии `dem.tif`. Варианты:
  «Позже», «Использовать плоскую поверхность», «Загрузить с Copernicus».
  При наличии файла диалога нет, включая реальный, тестовый и пользовательский
  рельеф. Проверка покрытия сцены остаётся частью валидации входа.
- Выбор плоской поверхности создаёт изменённую сцену, не запускает расчёт.
