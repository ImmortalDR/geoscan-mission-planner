# Ограничение критерия близости баз числом галсов — 2026-09-29

В H1 критерий суммы взвешенных обратных квадратов расстояний применяется
только при практически равной основной стоимости и одинаковом числе галсов.
Кандидаты с разным числом галсов сохраняют прежний взаимный порядок по стоимости,
углу и метке. Для нескольких углов вторичная сортировка действует только внутри
непрерывных блоков одинакового числа галсов; поэтому она не может переставить
кандидата через вариант с другим числом галсов. При равной близости сохраняется
первичная сортировка. Построение сетки не менялось этой правкой.

Проверки: 20 тестов сетки/критерия и 14 тестов кандидатов/покрытия прошли;
22 bundle прошли проверку контракта. Канонический и поставляемый файлы совпадают.
