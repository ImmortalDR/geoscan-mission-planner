# Редактор сцены и БВС — 27.09.2026

Проверено на тестовом сайте https://45.87.246.124:9443/.

- В панелях используются порядковые названия Job, Base, UAV и названия типов зон.
  Новые объекты получают такие идентификаторы. У импортированных данных
  внутренние идентификаторы сохраняются, чтобы не ломать связи и сертификаты.
  Изменяемое пользовательское название хранится отдельно в `name`.
- Выбор объекта связан с выделением Mapbox Draw; клик на карте выделяет строку,
  клик по строке выделяет объект и при необходимости подводит к нему карту.
  У объектов есть кнопки удаления, доступна отмена. Выбор карточки БВС выделяет
  его маршруты, клик по маршруту открывает соответствующую карточку.
- Карточки БВС раскрываются стрелкой, которая меняется на крестик; свойства
  имеют отдельный заголовок и фон. Отметки таблицы не пересоздают всю карточку.
- Таблица баз: старт и финиш — одна площадка либо любая подходящая;
  дозарядка — произвольное подмножество, все подходящие или ни одной.
  Старые ограничения показаны конкретными отметками. При редактировании
  таблицы refuel_sites получает явное значение до изменения конечных точек.
  Кандидатные и неподходящие по роли площадки нельзя выбрать.
- При удалении базы или смене её роли исключаются недоступные ссылки БВС;
  фиксированные недоступные старт/финиш переключаются на подходящую площадку.

## Проверки

`web/tests/editor_rules.cjs`: 4200 переключений и 100 конфигураций,
порядковые имена, перенос старой политики и удаление ссылок.
`tests/api/test_editor_site_choices.py`: все 100 конфигураций приняты контрактом
H2; фактические разрешения старт/финиш/дозарядка совпадают с выбором таблицы.
Вместе с существующими тестами промежуточной зарядки: 4 passed, 20 deselected.

`web/tests/h3_editor_smoke.py`: физический клик на базу на карте, обратное
выделение из списка, дублирование Job_1, удаление и undo, раскрытие карточки,
переключения таблицы и сохранение. S00 с явными настройками прошёл H1/H2/H3:
SAFE, 100%, время миссии 1183.32 с; ожидание результата в браузере 15.77 с.
Это замер S00, не оценка скорости сложных сцен.

Сценарий S10 проверяет разные роли баз. После последней правки обновления
таблицы отдельно повторены её переключения и desktop/mobile-вёрстка:
`table-layout.json`, `fleet-desktop.png`, `fleet-mobile.png`. Ошибок JavaScript нет.

Корректность формата и соблюдение выбранных баз не гарантируют физическую
выполнимость любого набора ограничений: ресурс, датчики и времена проверяет H2/H3.
