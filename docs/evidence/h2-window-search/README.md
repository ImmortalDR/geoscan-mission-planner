## Границы эвристики

В дополнительном варианте все аппараты приземляются на время объединения запретов,
даже если конкретный запрет пространственно локален. Обычный вариант сохраняет
пространственную обработку. Промежуточные посадки между окнами выбираются из
пересечения разрешённых конечных баз и баз дозарядки. Поэтому вспомогательный
вариант не перебирает все допустимые расписания; сравнение с исходным сохраняет
лучший полный проверенный план по выбранной метрике. Геометрию галсов не меняем.
Объединённый план проходит H2, затем независимый H3, как прежде.
