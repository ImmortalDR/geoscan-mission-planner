# Единый автоматический расчёт, 27.09.2026

Рабочий контур: https://45.87.246.124:9443/.
В UI удалены глубина и ориентир поиска. Браузер отправляет только сцену,
метрику, фиксированный seed и режим live. API по умолчанию задаёт deep/180,
сохраняя технические переопределения для экспериментов.

Routing использует детерминированную раннюю остановку: 400 тыс. обращений
к таблицам без строгого улучшения лучшей допустимой табличной оценки.
Улучшение сбрасывает счётчик; до нахождения допустимого кандидата критерий
отключён. Общий глубокий предел — 1,5 млн обращений, 1000 оценок блоков,
7 финалистов. Блочный поиск сохраняет остановку после прохода без улучшений.
Для маленьких задач терпение сокращается до 20 тыс. обращений. Модель времени,
геометрия, запас энергии, алгоритм разведения и независимые проверки H3 прежние.

Проверка выполнена настоящими нажатиями в Chromium: открытие шаблона S18,
сохранение отдельной копии, запуск обеих метрик без настроек, отображение
итоговой метрики и проверка отсутствия горизонтального скролла на 390/360 px.
Сохранённая копия: «S18 — автоматический расчёт». Requests, параметры backend,
контрольные суммы и сертификаты находятся в `results.json`.

| Метрика | Миссия, мин | Налёт, мин | Ответ в браузере, с | H3 |
|---|---:|---:|---:|---|
| makespan | 235.709 | 691.635 | 206.3 | SAFE, 100.000000% |
| total_flight | 348.565 | 663.216 | 209.1 | SAFE, 100.000000% |

Время в браузере включает загрузку и отрисовку результатов. Headless-браузер
работал на той же машине, что и сервер; эти значения нельзя прямо сравнивать
с прежними локальными замерами CLI как чистую скорость алгоритма.

Результат makespan совпал с прежним глубоким/обычным по контрольной сумме:
`ed9060a07f5f108cb8080c5ce9aafdd0e9d54ed17eb344b0317337d6afbf8b99`.
Для makespan ранняя остановка сработала после примерно 400 тыс. обращений
вместо предельных 1,5 млн. Для total_flight поиск дошёл до общего предела:
последнее улучшение произошло менее 400 тыс. обращений назад. Налёт снизился
с прежних 672,022 до 663,216 мин. Ранняя остановка не является доказательством
глобального оптимума.

Проверки: 30 тестов H2, 41 API/terrain тест, 22 bundle-контракта и четыре H2
приёмочных сценария; JavaScript syntax и браузерная проверка пройдены.
