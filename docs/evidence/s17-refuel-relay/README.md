Оба критерия дали одинаковые маршруты; совпал `solution_sha256`.
У коптера: Base_0 → Job_0 → Base_1, обслуживание 420 с,
затем Base_1 → Job_1 → Base_2. У самолёта: Base_0 → Job_2 → Job_3 → Base_2.
Все три вылета, совместимость датчиков, последовательность площадок,
продолжительность обслуживания и полное покрытие проверены утверждениями.
`routes.png` построен из фактических точек маршрута: локальные змейки без
перескоков между удалёнными галсами. Отдельные локальные прогоны полного
конвейера заняли 12.33 и 14.67 с. Время API включает запуск worker,
сериализацию, хранение и опрос раз в 3 с; замеры единичные.

Первая черновая геометрия попадала длинными галсами точно на границы
30-метровых ячеек DEM. Ошибка обратного преобразования порядка 1e-10 м
выбирала соседнюю ячейку и давала ALTITUDE_INCONSISTENT. В итоговом примере
начало локальных координат сдвинуто на 7.3/7.7 м, чтобы исключить это
вырожденное положение. DEM, алгоритмы и допуски проверок не менялись.
Общая проблема численной устойчивости на точной границе растра этим
изменением шаблона не исправляется.

INFEASIBLE; подпись предупреждает об ожидаемом отрицательном результате.
