## Проверенный релиз

На `https://45.87.246.124/` проверен релиз `20260925-reviewer-3`,
исходники `16441b1a01687034d07bf47f0491f99744650e21`.
Служба `geoscan-mvp.service` активна и включена в автозапуск; nginx принимает
HTTPS на 443, приложение использует PostgreSQL. Последующие коммиты добавляют
проверки, отчёты и настройку тестового порта Compose, не меняя код приложения.
Числа переноса относятся к моменту миграции, а не к текущему количеству записей.

Docker проверен отдельно, без замены рабочего systemd-развёртывания:
новые секреты, БД и тома, локальный HTTPS на 9443. Образ собран штатным Dockerfile
с `docker build --network host` и legacy builder; затем Compose запущен с
`up --no-build --wait`. Временный daemon не менял iptables и IP forwarding
рабочего сервера. Поэтому этот прогон подтверждает сборку и функциональность,
но не проверяет правила межсетевого экрана стандартной установки Docker.
GitHub Actions с BuildKit остаётся отдельной проверкой: статуса закрытого
репозитория через имеющийся SSH-доступ получить не удалось.
По завершении временные контейнеры, сети и тома удалены, тестовый daemon остановлен.

Перезапускался только тестовый контейнер приложения. Полный перезапуск хоста,
восстановление из резервной копии и испытания на 16 CPU / 64 ГБ здесь не заявлены.

## Ограничения

Сбой подключения на стенде не скрыт: добавлен ограниченный повтор только
установления соединения (не SQL-записей), чтение статуса без полной траектории
и гарантированная очистка дочернего процесса при исключении в API.

Итоговый прогон (`load/`): 358 запросов, 0 ошибок 5xx, 9 принятых планов SAFE.
При 32 пользователях приняты 4 плана, 28 получили 429; p95 HTTP 17068.016 мс.

Предыдущий нагрузочный прогон (`load-before/`): 373 запроса, 0 ошибок 5xx, 9 принятых планов SAFE.
При 32 пользователях приняты 4 плана, 28 получили 429; p95 HTTP 17946.634 мс.
Значительная задержка на 2 CPU является ограничением этого стенда.
Изменение файлового обработчика не дало подтверждённого выигрыша p95 в этом
прогоне; из двух измерений нельзя делать статистический вывод об ускорении.

Снимки подложки реальны, но имеют ограниченное пространственное разрешение
и не заменяют DSM/проверку препятствий. SAFE не является разрешением на полёт.
CSV регрессии не является доказательством глобальной оптимальности.

CI публикует свои отчёты отдельно в GitHub Actions artifacts; результаты CI
не следует считать полученными до фактического завершения workflow.
