## Изменение

Число рядов теперь ceil(width/spacing) с округлением близкого к целому отношения
(rel_tol=1e-10, abs_tol=1e-10). Центры равношироких полос находятся внутри зоны,
шаг width/count не превышает заданный с точностью машинного округления.
Обычный sweep и complete_parallel_sweep используют общий helper. Полное покрытие
по-прежнему проверяется физическими полосами датчика.

Дополнительный критерий при почти равной основной стоимости:
`sum(weight_base / (distance(endpoint, base)^2 + 1 m^2))` — максимум по всем
концам галсов и действующим стартовым базам. Вес = число совместимых по датчику
и ветру БПЛА с этой закреплённой базой или свободным стартом. Один аппарат
учитывается на каждой доступной стартовой базе один раз. Кандидатные и площадки
только для посадки исключены. Близость не заменяет ресурсные проверки H2.

Равенство основной стоимости: abs_tol=1e-6 м, rel_tol=1e-9, сравнение с минимумом
группы, чтобы избежать нетранзитивных цепочек. Приоритет остаётся у основной
стоимости, допустимости манёвров и полноты покрытия. Для равенства вторичного
критерия есть детерминированный порядок по углу/метке. В coverage_meta добавлены
base_weights и base_proximity_score; обязательный контракт не менялся.
