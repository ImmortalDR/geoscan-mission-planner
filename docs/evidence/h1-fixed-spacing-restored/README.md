Для некратной ширины восстановлены исходные число пробных линий и смещение:
ceil(width/spacing)+1, first=lower+(width-(count-1)*spacing)/2;
линии снаружи зоны отбрасываются. Узкая зона получает один центральный галс.

rel_tol=1e-10, abs_tol=1e-10: выбирается внутренняя фаза решётки с отступом
полшага, которая раньше случайно получалась при положительной погрешности
округления. Для 320 м / 80 м это четыре галса 40, 120, 200, 280 м.

защищён от численной погрешности. Эталон первого галса S00 возвращён к
исходным координатам до широкой правки сетки.

и одинаковом числе галсов. Назначение БВС, модель времени и проверки H2/H3
