## Материалы и границы

`system.json` / `system.junit.xml` — общий прогон; `dataset.txt` и
`contract.txt` — проверки данных; `local-service.json` — локальные LIVE
расчёты и экспорт; `source-check.json` — сверка исходников.

В LIVE-прогоне WebGL-контекст после инициализации снимался для устойчивой
проверки DOM: `local-service.png` не доказывает отрисовку карты. Браузерный
CI smoke по умолчанию требует непустого изображения карты. На данном
стенде два захвата WebGL завершились таймаутом; локальный прогон ролей
выполнен с `GMP_BROWSER_SKIP_WEBGL=1`, что отражено в `browser-roles.json`.
Пропуск не включён в workflow GitHub Actions.
Длительности относятся к данному стенду и одновременной нагрузке тестов.
Docker-контейнеры в этом прогоне не запускались: проверена упаковка контекста,
а прежние Docker-измерения лежат отдельно и относятся к своим версиям.
