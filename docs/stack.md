# Стек и зависимости

Установщик: `python3.12 scripts/install.py`. Точные версии находятся в
`requirements.txt`, а транзитивные зависимости зафиксированы в `requirements.lock`;
установщик выполняет `pip check` и проверяет импорт
нативных библиотек отдельным процессом. Для изолированного контура поддержан
`--wheelhouse /path/to/wheels` без обращения к PyPI.

| Библиотеки / платформа | Использование |
| --- | --- |
| Python 3.12 | Проверенная среда исполнения |
| FastAPI, Starlette, Uvicorn, Pydantic, python-multipart | HTTP API, проверка данных, загрузки |
| PostgreSQL 16, psycopg 3 | Транзакционное хранение JSONB, сессии и ограничение попыток входа |
| NumPy 1.26.4 | Численные операции на совместимых со старым CPU колёсах |
| Shapely 2.0.7 / GEOS | Геометрические операции |
| pyproj / PROJ | Системы координат |
| rasterio / GDAL | DSM и GeoTIFF |
| OR-Tools 9.10.4067 | Routing Solver / Guided Local Search; CP-SAT сохранён в историческом контуре |
| PyYAML, Jinja2 | Конфигурация и шаблоны |
| ReportLab, python-docx, matplotlib | Экспорт отчётов |
| pytest, Hypothesis, httpx | Регрессия, инварианты и нагрузочные HTTP-тесты |
| MapLibre GL, Mapbox GL Draw, Lucide | Локально поставляемые карта, редактор и значки |
| nginx | TLS и обратный прокси |

Лицензии браузерных библиотек сохранены в `web/h3/vendor/`; происхождение
изображений указано в `web/h3/imagery/manifest.json`. Источники и лицензии DSM
находятся в `data/sources/`. Алгоритмы не заявляются собственными разработками
авторов библиотек: вклад команды описан отдельно в `algorithms/catalog.json`.

## Старое и новое оборудование

Используется единый совместимый набор зависимостей. Автоматически меняются
число процессов и длина очереди, а не версии численных библиотек посреди
установки. `scripts/doctor.py` учитывает affinity и cgroup v2 лимиты.
Неподдерживаемые бинарные инструкции выявляются пробным импортом; установщик
завершается с ошибкой и журналом вместо запуска неисправного приложения.

Для профиля 16 CPU / 64 ГБ расчётный предел составляет 8 параллельных задач.
Это конфигурация, которую необходимо испытать на реальном целевом сервере.
