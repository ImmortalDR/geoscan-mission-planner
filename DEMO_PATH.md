# H3 demo path

Владелец прогона: Данила Бессмертный. Результат ручного прогона записывается
отдельно: автоматические тесты не подменяют приёмку человеком.

## Основной проход

1. Открыть HTTPS-адрес службы. Без кода API проектов и экспорт недоступны.
2. Войти общим кодом. Не показывать код или cookies на записи презентации.
3. Создать рабочую копию S00 из каталога. Посмотреть карту и параметры БВС.
4. Запустить настоящий расчёт makespan. Увидеть очередь/ход работы и результат.
5. Проверить статус, покрытие, расписание, нарушения и идентификатор проверки.
6. Скачать JSON, KML, GeoJSON, PDF и DOCX. Открыть отчёты, проверить кириллицу.
7. Открыть эталон отдельно: режим явно обозначен, метрики сравниваются,
   результат не выдаётся за новый расчёт или доказанный глобальный оптимум.
8. Создать новую версию: изменить геометрию, площадку или параметры БВС.
   Исходная версия и её результат сохраняются; новый вход требует нового расчёта.
9. Загрузить тот же вход ZIP и отдельными файлами. Некорректная геометрия и
   неполный комплект отклоняются с понятной ошибкой.

## Проверка отказа и рекомендации

1. Создать S06 с удалённой базой и запустить настоящий расчёт.
2. Проверить доказательство отказа. Ошибка или тайм-аут сами по себе не являются
   доказательством INFEASIBLE.
3. Посмотреть проверенную альтернативу с ближней площадкой, её изменения,
   новый расчёт и отдельный сертификат. Только затем применить её новой версией.
4. Убедиться, что исходный отказ не исчез и не заменён результатом другой сцены.

## Большая и временная сцены

- **Сценарий vs проект:** сценарий = шаблон каталога; проект = editable копия.
  Групповые для H2: S01 (4 БВС), S05 (2), S11 (5). Подробнее: [`docs/contract/H2_TEST_SCENES.md`](docs/contract/H2_TEST_SCENES.md).
- МГУ S01: 100 км², оба критерия раздельно; сравнить метрики без требования
  одинаковой формы маршрутов.
- Орехово S03: показать ожидание окончания запрета и соблюдение временного окна.
- S09: отказ по ветру без выдачи исполнимой миссии.

## Сохранность и защита

- После перезапуска geoscan-h3 проект и экспорт остаются доступны.
- Неверные коды ограничиваются по попыткам; изменения без CSRF отклоняются.
- Новый проект показывает срок хранения; шаблоны демокаталога не удаляются.
- Невалидный ZIP, path traversal, NaN и неизвестные идентификаторы отклоняются.
- При недоступности карты/DSM/расчёта виден сбой, а не выдуманный успешный результат.

## Честный fallback

Если live-расчёт не завершился, зафиксировать ошибку и отдельно открыть
эталонный режим неизменённого демонстрационного входа. Не объявлять это
успешной live-приёмкой. Показывать ограничения DSM, непрерывной модели
съёмки и упрощённой динамики, не называть результат разрешением на полёт.
