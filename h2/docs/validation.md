## Сценарии H2

- S04: один аппарат, три задачи, два вылета и обслуживание.
- S05: два аппарата, исходный конфликт, устранение задержкой старта.
- S10: разрешённые разные старт/посадка.
- Все три создаются воспроизводимо скриптом `scripts/demo.py`; generated JSON и HTML находятся только в `artifacts/demo`.
- Отдельные отрицательные проверки: нехватка ресурса, запрет назначения,
  конфликт между waypoints, временные запреты, неверная геометрия/метрики,
  отсутствие обязательного обслуживания, подмена AMSL, неизвестные id.
- Anytime-тест действительно улучшает zigzag-baseline; отдельный тест показывает
  разные допустимые решения для makespan и total_flight.
