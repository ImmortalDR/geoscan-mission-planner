# H2 — планирование и разведение БВС

Получает отдельные полные галсы H1 и ограничения сцены. Строит граф,
предрасчитывает время/ресурс для каждого типа БВС, оптимизирует маршруты
с OR-Tools Routing и подробно проверяет финальные траектории.

[Текущая модель](../docs/current-planning.md) · [Реализация](docs/routing.md) ·
[Вход сцены](docs/scene.md) · [Выход](docs/output.md) ·
[Разведение](docs/collision.md) · [Проверки](docs/validation.md).

Используйте общее окружение из [корневого README](../README.md).
Из корня репозитория:

```bash
.venv/bin/python -m pytest -c pyproject.toml h2/tests -q
.venv/bin/python scripts/validate_h1_h2_contract.py
```

В LIVE API используется Routing. Предыдущие алгоритмы сохранены в коде
для совместимости CLI и регрессионных тестов; их результаты не следует
смешивать с измерениями текущего контура. Отдельный старый viewer в поставку
не входит: общий интерфейс расположен в `web/h3/`.
