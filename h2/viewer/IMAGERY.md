# Спутниковая подложка просмотрщика

Просмотрщик показывает реальные RGB-данные Sentinel-2C от **28.05.2025**,
10 м/пиксель. Снимок скачан на сервер: для его отображения браузеру не нужны
сторонний картографический сервис, API-ключ или внешний запрос за тайлами.

## Привязка к заданиям

В текущих 12 H2 bundles используется EPSG:32637. Фрагмент изображения сохранён
в той же проекции, без переноса или изменения координат задач. Границы фрагмента
и SHA-256 записаны в `static/imagery/manifest.json`. SVG-изображение расположено
перед слоями задач; масштабирование и панорамирование одинаковы для всех слоёв.

Эти H2 fixtures не являются тремя районными сценами H3. Их координаты покрывают
единый московский участок. Для H3 отдельно подготовлены МГУ, Переделкино и
Орехово - Домодедовская в `h3/web/h3/imagery`.

«Схема» возвращает исходный вид без снимка, это не карта OpenStreetMap.
При несовпадении проекции, отсутствии покрытия или ошибке загрузки задания
остаются видимыми, а интерфейс сообщает, что снимок недоступен.

## Происхождение

- [Sentinel-2 COG, Element 84](https://registry.opendata.aws/sentinel-2-l2a-cogs/).
- [Исходный STAC-снимок](https://earth-search.aws.element84.com/v1/collections/sentinel-2-l2a/items/S2C_37UDB_20250528_0_L2A).
- [Лицензия Copernicus Sentinel](https://cds.climate.copernicus.eu/licences/ec-sentinel).
- Атрибуция: **Contains modified Copernicus Sentinel data 2025**.

`static/imagery/source.json` содержит исходное STAC-описание.
`moscow.tif` является трёхканальным RGB-изображением, не DEM/DSM. Снимок не
подтверждает актуальность препятствий, разрешений или безопасность полёта.
Разрешение 10 м не предназначено для точной проверки отдельных зданий.

## Воспроизведение

Для подготовки нужны rasterio, numpy и Pillow; они уже доступны в окружении H3.
Из корня H2:

```bash
../h3/.venv/bin/python scripts/prepare_viewer_imagery.py \
  --fixtures fixtures --output /tmp/viewer-imagery-new
```

Скрипт читает только нужное окно исходного COG, без загрузки полного тайла,
отказывается перезаписывать готовый manifest и проверяет отсутствие пустых
пикселей. Исходные bundles открываются только для чтения.

Браузерная проверка с Playwright и Pillow:

```bash
python tests/browser_map_imagery.py --output artifacts/viewer-imagery-check
```

Проверка поднимает временный локальный сервер, не вызывает планировщик и не
перезапускает рабочие службы. Проверяются геопривязка, все 12 сцен, переключение,
масштабирование, мобильные размеры и поведение при ошибке загрузки.
