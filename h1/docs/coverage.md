# Построение покрытия

Рабочий backend — `diy_lawnmower_v1`: собственная геометрическая реализация
на Shapely. Fields2Cover не входит в обязательный путь запуска.

Для зоны H1 выбирает параметры съёмки, допустимые направления и шаг галсов
по профилю датчика, высоте/GSD и перекрытию. Генератор учитывает составную
геометрию и отверстия; проверка покрытия отсеивает неполные кандидаты.
При равенстве основных показателей и одинаковом числе галсов дополнительная
метрика учитывает близость концов галсов к базам совместимых БВС.

H1 формирует исходные галсы. Интеграционный адаптер передаёт H2 полные
направленные варианты отдельных галсов без изменения их геометрии.
Граф, назначение БВС, порядок посещения и межзональные перелёты строит H2.
