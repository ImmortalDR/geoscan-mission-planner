# Объединённый MVP Geoscan, 22.09.2026

Основной адрес: https://45.87.246.124/ (HTTPS, порт 443).
Общий код доступа сохранён. Адрес с портом 8443 перенаправляет на основной.

## Что работает

Настоящий расчёт: канонический H1 строит задачи покрытия, отдельный H2
назначает БВС и строит расписание/траектории, H3 независимо проверяет результат
и только после этого выдаёт сертификат. Старый `gmp.planner` не является
планировщиком нового LIVE-режима. Эталоны доступны отдельно и явно помечены.

Есть редактор сцены и БВС, реальные спутниковые подложки МГУ/Переделкино/Орехово,
DSM, загрузки ZIP/GeoJSON/KML/GeoTIFF, версии, история, воспроизведение маршрутов,
проверенные рекомендации, JSON/GeoJSON/KML/PDF/DOCX и сертификат.

## Репозитории и запуск

| Модуль | Источники | Репозиторий |
| --- | --- | --- |
| H1 | `/root/h1/h1_coverage` | Канонический локальный пакет без отдельного Git-репозитория |
| H2 | `/root/h2` | `TPRozov/h2` |
| H3, API, интерфейс | `/root/h3` | `ImmortalDR/geoscan` |
| Датасет | `/root/h3/data` | Неизменённый внешний набор данных |

Рабочие каталоги не используются как изменяемый runtime. Служба
`geoscan-mvp.service` запускает снимок `/opt/geoscan-mvp/current`, указывающий
на `/opt/geoscan-mvp/releases/20260922-mvp-3`. nginx:443 передаёт запросы
в `127.0.0.1:8092`. Автозапуск включён.

Python-окружение переиспользуется из `/opt/geoscan-h3/venv`, но код трёх модулей
импортируется из нового снимка, а не из прежнего приложения H3.
Состояние: `/var/lib/geoscan-h3`; код доступа вне исходников.

Старый H2 viewer оставлен только на loopback 8090. Старый `geoscan-h3.service`
остановлен и отключён от автозапуска. Его runtime сохранён для отката.
Чужие незакоммиченные изменения сохранены; Git-коммиты и push не выполнялись.
